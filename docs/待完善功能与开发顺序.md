## 已有功能

- Supabase Auth 登录/注册、个人显示名称。
- 项目创建；登录用户可浏览项目名称并主动加入项目。
- 项目成员可创建、编辑、指派、变更状态/优先级、删除任务和发表评论。
- 任务、项目和评论数据保存在 Supabase，刷新后仍可读取。
- 项目成员关系已改为直接关联项目；迁移保留了原项目、成员、任务和评论数据，并删除团队数据结构。

## 当前权限提示

所有登录用户都能浏览项目名称并自行加入。若 Supabase 开放注册，任何新注册账号都能加入项目；任务、评论和成员资料仍只向项目成员开放。若未来需要限制加入，再增加管理员审批或私密加入方式。
